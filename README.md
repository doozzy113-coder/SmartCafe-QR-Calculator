# QR-меню від Smart Cafe — калькулятор v7

## Що змінено

- Додано перемикач світлої та темної теми у верхній панелі.
- Темна тема увімкнена за замовчуванням.
- Вибір теми зберігається у браузері.
- Повернуто м’який фіолетовий градієнт на фоні та у першому екрані.
- Темний режим адаптовано для полів, карток, модальних вікон, звіту, FAQ та скролбарів.
- Дизайн став сучаснішим, але без надмірного світіння, декоративних бейджів і зайвих ефектів.
- Формування PDF залишається світлим і мінімалістичним, незалежно від теми сайту.
