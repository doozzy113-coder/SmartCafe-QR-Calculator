# QR-меню від Smart Cafe — калькулятор v8.1

## Виправлення перемикання тарифів

У v8 перемикач Lite Integration / стандартні тарифи змінював ліву частину форми, але правий підсумок міг залишатися на Small.

Причина: під час попередньої перебудови JavaScript випадково були видалені допоміжні функції, які оновлюють:
- назву тарифу;
- ціну тарифу;
- щомісячний та разовий підсумок;
- обрані послуги;
- підсвічування активного тарифу.

У v8.1 ці функції повернено. Для перемикача формату також додано окремий обробник події `change`.

## Логіка, яка залишилася без змін

- Lite Integration: кількість ID × ₴150 на місяць.
- Small–Unlimited: тариф визначається за середньою кількістю замовлень на одну локацію.
- 1 000 замовлень / 5 локацій = 200 → Small.
- 1 000 замовлень / 2 локації = 500 → Large.
